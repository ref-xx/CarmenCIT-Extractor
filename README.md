# CarmenCIT-Extractor

Where in the world is Carmen Sandiego MSDOS 1984 version City Data Files Reader-extractor.

The program reads and cathegorizes <city>.CIT files. This is still a work in progress.

Currently the program:
-reads and views city images. 
-Reads the headers and all strings available
-Does not categorize numerical fields yet

No file export options available yet but you can copy-paste texts and save images if needed.
